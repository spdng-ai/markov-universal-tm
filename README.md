# Один универсальный нормальный алгоритм Маркова

Учебный проект по теории вычислений: один фиксированный набор из 800 правил
замены (нормальный алгоритм Маркова, алфавит 88 букв), который исполняет
программу любой детерминированной машины Тьюринга. Машина и её лента
записываются прямо во входное слово, а таблица правил от машины не зависит.

У нормального алгоритма нет ни переменных, ни циклов, ни головки — только
упорядоченный список правил «подстрока → подстрока» и слово. И этого
механизма хватает на универсальную симуляцию, что проект и показывает.

Конструкция, доказательство корректности и подробности проверок —
в [REPORT_RU.md](REPORT_RU.md).

## Запуск

Нужен только Python 3.10+ (проверял на 3.14), сторонних пакетов нет.

```bash
python3 app.py                                      # что это + демо на 7 примерах (≈25 с)
python3 app.py --menu                               # интерактивное меню
python3 run.py examples/invert.json 01011 --trace   # своя машина и вход, с трассой шагов
python3 verify.py                                   # полная проверка (≈1 мин)
```

На Windows — `py -3 app.py` или `start.bat`. Проверки запускайте без `-O`:
там `assert`. Примеры запусков смотрите в `evidence/`.

## Своя машина

Машина описывается JSON-файлом; проще всего скопировать один из `examples/`:

```json
{"name": "инверсия", "start": 1,
 "transitions": [
   {"source": 1, "read": "0", "target": 1, "write": "1", "move": "R"}
 ]}
```

Номера состояний — любые положительные целые (хоть 257). Символы ленты:
`0`, `1`, `_` (пустая ячейка); направления: `L`, `R`, `S`. Для пары
(source, read) допускается одна команда. Состояние без исходящих команд
останавливает машину. Таблицу Маркова при этом менять не нужно — меняется
только входное слово.

## Что внутри

| Файл | Роль |
|---|---|
| `rules.json` | сами 800 правил — они и выполняют вычисление |
| `engine.py` | общий интерпретатор замен, про машины Тьюринга не знает ничего |
| `codec.py` | запись машины и входа в слово, чтение результата |
| `fixed_rules.py` | генератор таблицы: один раз разворачивает весь список |
| `run.py` | CLI: машина + вход, трасса конфигураций, микро-трасса замен |
| `app.py` | демо-приложение и меню |
| `literal_run.py` | запуск общего интерпретатора на готовом слове, без кодировщика |
| `reference.py` | обычный симулятор МТ, используется только для сверки |
| `verify.py` | дифференциальные проверки: НАМ против независимого эталона |
| `examples/` | примеры входных машин |
| `evidence/` | протоколы прогонов |
| `REPORT_RU.md` |пояснение|

Последний прогон `verify.py`: 3 884 запуска, 13 395 сравнённых переходов,
около 9,5 млн замен. Каждая стабильная конфигурация сверялась с независимым
обычным симулятором, включая все ячейки представленного участка и положение
головки. Журнал — `evidence/test_run.txt`, подробный отчёт —
`evidence/verification.json`. Тесты проверяют конкретные исполнения;
доказательство — в отчёте, тесты его не заменяют.

Повторно получить ту же таблицу: `python3 fixed_rules.py` (генератор не
принимает машину на вход и всегда выдаёт один и тот же список).

## Замечания

- `status=limit` значит, что работа прервана по бюджету замен. Это не
  доказательство зацикливания.
- `--micro N` показывает первые N буквальных замен — видно, как
  буква-«курсор» бегает по слову.
