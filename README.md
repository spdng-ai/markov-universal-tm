# Один универсальный нормальный алгоритм Маркова

Учебный проект по теории вычислений: один фиксированный набор из 6962
правил замены (нормальный алгоритм Маркова, алфавит 348 букв), который
исполняет программу любой детерминированной машины Тьюринга. Машина и её
лента записываются прямо во входное слово, а таблица правил от машины
не зависит.

У нормального алгоритма нет ни переменных, ни циклов, ни головки — только
упорядоченный список правил «подстрока → подстрока» и слово. И этого
механизма хватает на универсальную симуляцию, что проект и показывает.

Конструкция и подробности —
в [REPORT_RU.md](REPORT_RU.md).

## Режимы — задачи практикума

Основной набор `examples/` — решения задач 1.1–1.14 практикума
А.Н. Тихомировой, Н.В. Сафоненко «Практикум по теории алгоритмов»
(МИФИ, 2011, глава 1), переведённые в формат входных машин:

| Файл | Задача | Что делает |
|---|---|---|
| `task_1_01.json` | 1.1 | заменить все «a» на «b» |
| `task_1_02.json` | 1.2 | дописать 1 в конец слова (пустое слово — Ω1) |
| `task_1_03.json` | 1.3 | дописать после слова первую букву |
| `task_1_04.json` | 1.4 | дописать в конце последний символ |
| `task_1_05.json` | 1.5 | заменить каждую комбинацию «012» на «***» |
| `task_1_06.json` | 1.6 | предыдущее число в унарном коде |
| `task_1_07.json` | 1.7 | копия слова в обратном порядке после «*» |
| `task_1_08.json` | 1.8 | копия в обратном порядке сразу за словом |
| `task_1_09.json` | 1.9 | копия слова в прямом порядке после «*» |
| `task_1_10.json` | 1.10 | копия в прямом порядке без разделителя |
| `task_1_11.json` | 1.11 | развернуть слово на месте |
| `task_1_12.json` | 1.12 | палиндром? Ω — да, Ω1 — нет |
| `task_1_13.json` | 1.13 | унарная псевдоразность a ∸ b |
| `task_1_14.json` | 1.14 | каких символов больше: «+», «-» или «=» |

Легенда алфавита: `0 1 2 a b * ∸ + - =` — рабочие символы задач; `c d e f` —
помеченные символы 0′ 1′ 0″ 1″ (одна буква на ячейку); `σ` — маркер начала
ленты (вход задач начинается с него); `_` — пустая ячейка. Остановочные
состояния задач: Ω = 20 (нормальный останов), Ω1 = 21 (ошибка входа).
Плюс четыре тривиальных служебных демо: `invert`, `immediate`,
`loop_stay`, `loop_right`.

Задачи 1.15–1.17 практикума рассчитаны на многоленточные машины и на
одноленточном симуляторе дословно не воспроизводятся — режимов для них нет
(см. REPORT_RU.md, раздел 1.3).

## Запуск

Нужен только Python 3.10+ (проверял на 3.13/3.14), сторонних пакетов нет.

```bash
python3 app.py                                      # что это + демо на задачах практикума (≈ 1 мин)
python3 app.py --menu                               # интерактивное меню
python3 run.py examples/task_1_11.json σ0011 --trace   # своя машина и вход, с трассой шагов
python3 verify.py                                   # полная проверка (≈ 2–4 мин)
```

На Windows — `py -3 app.py` или `start.bat`. Проверки запускайте без `-O`:
там `assert`. Примеры запусков смотрите в `evidence/`.

## Своя машина

Машина описывается JSON-файлом; проще всего скопировать один из `examples/`:

```json
{"name": "инверсия", "start": 1,
 "transitions": [
   {"source": 1, "read": "0", "target": 1, "write": "1", "move": "R"}
 ]}
```

Номера состояний — любые положительные целые. Символы ленты:
`0 1 2 a b * ∸ + - = c d e f σ _` (пустая ячейка — `_`); направления:
`L`, `R`, `S`. Для пары (source, read) допускается одна команда. Состояние
без исходящих команд останавливает машину. Таблицу Маркова при этом менять
не нужно — меняется только входное слово.

## Что внутри

Главные файлы: `rules.json` — сама таблица правил (она и считает),
`engine.py` — общий интерпретатор замен, `codec.py` — кодирование машины в
слово, `run.py` и `app.py` — запуск, `verify.py` — проверки,
`REPORT_RU.md` — отчёт с конструкцией и доказательством. Остальное понятно
по названиям.

Последний прогон `verify.py`: 1 598 запусков, 5 377 сравнённых переходов, ~24,4 млн замен (~2,3 минуты); полный протокол — `evidence/verification.json`. Каждая стабильная конфигурация сверялась с независимым
обычным симулятором, включая все ячейки представленного участка и положение
головки; задачи практикума дополнительно сверены с ожидаемыми ответами из
условий. Тесты проверяют конкретные исполнения; доказательство — в отчёте,
тесты его не заменяют.

Повторно получить ту же таблицу: `python3 fixed_rules.py` (генератор не
принимает машину на вход и всегда выдаёт один и тот же список). Примеры
задач: `python3 examples.py`.

## Замечания

- `status=limit` значит, что работа прервана по бюджету замен. Это не
  доказательство зацикливания.
- `--micro N` показывает первые N буквальных замен — видно, как
  буква-«курсор» бегает по слову.
- Буквы алфавита задач (`σ`, `∸`, помеченные символы) — обычные символы
  Юникода; в `rules.json` они записаны JSON-экранированием (`\u03c3`).
